## `$ cat mission.txt`

Policies often fail long before the policy itself fails.

A target is established. A measurable indicator becomes the proxy for success. Institutions begin optimizing the indicator, and the original outcome gets lost.

My work examines that gap.

I build analytical pipelines that connect **large datasets, spatial evidence, policy design, and decision-making**, then translate the results into recommendations that researchers, agencies, advocates, and policymakers can act on.

My current work spans:

`protected areas` · `clean energy` · `EV infrastructure` · `environmental regulation` · `geospatial analysis` · `AI` · `program evaluation`

# `$ ls ./featured-work`

## 01. National Protected-Areas Representation Pipeline

**Python · R · ArcGIS · PAD-US · USNVC · EPA Ecoregions**

National-scale spatial analysis evaluating whether increasing protected acreage translates into meaningful ecosystem representation.

- Analyzed **210 USNVC vegetation groups**
- Integrated national protected-area and ecological datasets
- Compared strict and broad definitions of protection
- Built rerunnable analytical workflows for research collaborators
- Translated spatial results into policy-relevant assessments of conservation targets

> `research-code-status: preparing public release`

---

## 02. Appalachian Climate Range Shifts

**Python · R · Geospatial Analysis · Conservation Policy**

Climate-driven range-shift analysis examining how wildlife conservation responsibility changes across political boundaries.

- Modeled **270 vertebrate species**
- Covered **13 Appalachian states**
- Constructed pairwise state co-responsibility matrices
- Examined mismatches between future species distributions and existing conservation planning

> `research-code-status: preparing public release`

---

## 03. Clarifying-Question AI Agent

**JavaScript · Node.js · Gemini API · Prompt Engineering**

Built for the Google Gemini API Developer Competition.

Instead of immediately answering an underspecified question, the system asks targeted follow-up questions and conditions the final API request on the user's actual objective.

[View repository →](https://github.com/vkenned2/Gemini-API-Call)

---

## 04. Automated TEM Analysis

**Python · Machine Learning · Autoencoders · Scientific Imaging**

Collaborative microscopy automation project developed through a Mic-Hackathon involving Oak Ridge National Laboratory and the Microscopy Society of America.

The work explored machine-learning pipelines for automated acquisition and feature recognition in transmission electron microscopy.

[Read the peer-reviewed publication →](https://doi.org/10.1088/2632-2153/ae1f5d)

---

## 05. EcoLeaders Platform Analytics

**Python · Program Evaluation · User Research · Decision Support**

Used engagement analytics and participant research to diagnose retention problems in a national environmental leadership platform.

**Result: 283% increase in engagement compared with the previous program cycle.**

The project combined:

`data analysis` → `participant interviews` → `program redesign` → `implementation` → `evaluation`
