About

vishal@github:~$ whoami

PhD Candidate | Policy Analyst | Researcher | Data-Driven Problem Solver

I work at the intersection of policy, spatial evidence, large datasets, and decision-making. My research asks a practical question: when a policy establishes a target, do the metrics used to measure success actually represent the outcome policymakers intended?

I build analytical workflows that turn complex environmental and energy data into evidence that researchers, agencies, advocates, and decision-makers can use.

Current focus: energy policy · protected areas · EV infrastructure · environmental regulation · geospatial analysis · AI · program evaluation

Featured Work

01 | National Protected-Areas Representation Pipeline

Python · R · ArcGIS · PAD-US · USNVC · EPA Ecoregions

National-scale spatial analysis evaluating whether increases in protected acreage translate into meaningful ecosystem representation.

Analyzed 210 USNVC vegetation groups

Integrated national protected-area and ecological datasets

Compared strict and broad definitions of protection

Built rerunnable analytical workflows for research collaborators

Translated spatial results into policy-relevant assessments of conservation targets

research-code-status: preparing public release

02 | Appalachian Climate Range Shifts

Python · R · Geospatial Analysis · Conservation Policy

Climate-driven range-shift analysis examining how wildlife conservation responsibility changes across political boundaries.

Modeled 270 vertebrate species

Covered 13 Appalachian states

Constructed pairwise state co-responsibility matrices

Examined mismatches between projected species distributions and existing conservation planning

research-code-status: preparing public release

03 | Clarifying-Question AI Agent

JavaScript · Node.js · Gemini API · Prompt Engineering

Built for the Google Gemini API Developer Competition. Instead of immediately answering an underspecified question, the system asks targeted follow-up questions and conditions the final API request on the user's actual objective.

View repository →

04 | Automated TEM Analysis

Python · Machine Learning · Autoencoders · Scientific Imaging

Collaborative microscopy automation work developed through a Mic-Hackathon involving Oak Ridge National Laboratory and the Microscopy Society of America. The project explored machine-learning pipelines for automated acquisition and feature recognition in transmission electron microscopy.

Read the peer-reviewed publication →

05 | EcoLeaders Platform Analytics

Python · Program Evaluation · User Research · Decision Support

Used engagement analytics and participant research to diagnose retention problems in a national environmental leadership platform.

Result: 283% increase in engagement compared with the previous program cycle.

data analysis → participant interviews → program redesign → implementation → evaluation

06 | Environmental Compliance & Management

EMS · ISO 14001 · RCRA · Environmental Reporting · Sustainability

BMW-aligned environmental compliance work focused on translating regulatory requirements into practical environmental-management systems for industrial and manufacturing settings.

Contributed to Environmental Management System (EMS) documentation aligned with ISO 14001

Developed dashboards for tracking environmental indicators and compliance metrics

Worked with environmental compliance reporting and hazardous-waste management concepts

Developed hazardous-waste protocols aligned with RCRA requirements

Analyzed state and federal environmental policy requirements

Created training and sustainability-communication materials for stakeholder use

industry-focus: automotive manufacturing · BMW environmental management · regulatory compliance
